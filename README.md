# Galactic Math Wars

A Star Wars-themed maths game. Pick a light-side hero, travel the galaxy map and beat the dark side by answering maths problems, all the way to Darth Vader on the Death Star.

- Five levels: Ewok (ages 4–5), Youngling, Padawan, Jedi Knight and Jedi Master
- Norwegian and English (⚙ settings)
- Works offline and can be added to the home screen on iPad/iPhone (Share → Add to Home Screen)

Everything is in `index.html`; no build step. A private fan project, not affiliated with Lucasfilm or Disney.
